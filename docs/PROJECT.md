# Telegram AI Bot Project

## Описание
Интеллектуальный Telegram-бот для групповых чатов, способный читать сообщения, различать участников, сохранять контекст, выполнять гибридный поиск по истории, понимать темы и извлекать факты. Основной фокус бота — работа с долгосрочной и краткосрочной памятью группы, а не просто мгновенные ответы. 

## Основные возможности (планируемые)
- Работа в фоновом режиме (ответы только при явном обращении)
- Сохранение истории сообщений в сыром виде
- Асинхронная суммаризация бесед
- Тематическая группировка обсуждений
- Гибридный поиск: семантический (векторный) + полнотекстовый + фильтрация по метаданным
- Формирование deep link на исходные сообщения
- Структурированная память: факты, решения, события, задачи

## Текущий статус
- **Этап 0 (Foundation)** — Подготовка инфраструктуры, архитектуры, конфигурации и развертывания.

## Используемые технологии
- **Язык**: Python 3.13+
- **Фреймворк**: aiogram
- **База данных**: PostgreSQL (с pgvector для семантического поиска)
- **Кэш/Очереди**: Redis
- **ORM**: SQLAlchemy + Alembic
- **LLM**: Google Gemini API (абстрагированный провайдер)
- **Контейнеризация**: Docker
- **Тестирование**: pytest

## Основные принципы разработки
- **Безопасность инфраструктуры**: Развёртывание не должно ломать существующие сервисы на production VPS.
- **Модульность**: Абстрагирование LLM-провайдера и разделение слоев памяти.
- **Неблокируемость**: Тяжелые операции (суммаризация, создание эмбеддингов) должны выполняться асинхронно в фоне.
- **Неразрушающая история**: Все исходные сообщения сохраняются, никакие слои памяти не заменяют их.
- **Масштабируемость**: Архитектура должна поддерживать мульти-чат без захардкоженных ID.
